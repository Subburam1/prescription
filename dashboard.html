Project Description

Our project, Prescription Analysis Dashboard, is a web-based analytics system designed to visualize and analyze medical prescription data effectively. The platform provides insights into doctors' prescription behaviors, hospital performance, and drug popularity trends. Users can interact with various visual charts such as bar graphs, pie charts, stacked bars, and maps to understand patterns clearly. Filters based on doctor names, hospitals, and cities help in narrowing down the data for deeper exploration. The dashboard enables healthcare teams to identify top-prescribing doctors, most prescribed drugs, and regional performance with real-time filtering. Additionally, the system includes a secure login page to ensure only authorized users can access the dashboard. This tool aids in decision-making, resource allocation, and improving prescription practices in healthcare facilities.
